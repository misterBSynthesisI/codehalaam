## Git Push Policy (MANDATORY)

> **After every code change (major or minor) AND docs update, you MUST push to GitHub.**
> Never leave local-only commits. The remote is the source of truth.

### Rules

1. **Always push** after committing — `git push origin main`.
2. **Split changes** into logical atomic commits before pushing.
3. **Use conventional commits**: `feat`, `fix`, `refactor`, `docs`, `chore` with a scope.
4. **Commit body explains WHY**, not what (the diff shows what).
5. **Update this file** (`agents.md`) if the workflow changes.
6. **Remote:** `https://github.com/misterBSynthesisI/codehalaam`
