## Philosophy

CODEHALAAM follows GitHub's Primer design system principles, enhanced with Apple's fluid interface design philosophy:

- **Constraint-based**: Every design decision serves a purpose
- **Accessible**: WCAG 2.1 AA compliant by default
- **Consistent**: Unified patterns across all interfaces
- **Performant**: Minimal CSS, optimized rendering
- **Fluid**: Motion starts from current value, inherits velocity, is interruptible

## Apple Design Principles Applied

### 1. Response — Kill Latency
- All buttons have instant `:active` feedback (`scale(0.97)` on press)
- Theme toggle has `:active` feedback (`scale(0.92)`)
- Tab navigation has `:active` feedback
- List rows highlight on press (not just hover)
- Feedback is continuous during interaction, not just at the end

### 2. Interruptibility — Springs Over Easing
All animations use Framer Motion springs (not CSS transitions) for gesture-driven elements:

```tsx
// Critically damped — no overshoot (Apple default for UI)
transition={{ type: 'spring', bounce: 0, duration: 0.4 }}

// Momentum-driven — slight bounce (only when gesture carried momentum)
transition={{ type: 'spring', bounce: 0.15, duration: 0.4 }}
```

### 3. Translucent Materials
The navbar and dropdown menus use `backdrop-filter` for Apple's material treatment:

```css
.material-toolbar {
  background: rgba(22, 27, 34, 0.72);        /* dark theme */
  backdrop-filter: blur(20px) saturate(180%);
}

html.light .material-toolbar {
  background: rgba(255, 255, 255, 0.72);      /* light theme */
  backdrop-filter: blur(20px) saturate(180%);
}
```

Content scrolls **under** the translucent chrome, not behind an opaque bar.

### 4. Typography — Optical Sizing
Tracking (letter-spacing) is **size-specific**, never one value for all:

| Size | Tracking | Leading | Rationale |
|------|----------|---------|-----------|
| Display (h1, 4xl-6xl) | `-0.02em` | `1.1` | Large text reads too far apart; tighten |
| Section (h2, 3xl) | `-0.015em` | `1.2` | Moderate tightening |
| Subheading (h3, 2xl) | `-0.01em` | `1.25` | Slight tightening |
| Body large (xl, lg) | `-0.005em` | `1.35` | Near zero |
| Small (xs, sm) | `+0.01em` | `1.5` | Positive for legibility |

### 5. Reduced Motion & Accessibility
Three independent media queries are supported:

```css
@media (prefers-reduced-motion: reduce) {
  /* Kill all animations, keep opacity/color changes */
  *, *::before, *::after {
    animation-duration: 0.01ms !important;
    transition-duration: 0.01ms !important;
  }
}

@media (prefers-reduced-transparency: reduce) {
  /* Make translucent surfaces opaque */
  .material-toolbar {
    background: var(--color-header-bg);
    backdrop-filter: none;
  }
}

@media (prefers-contrast: more) {
  /* Thicker borders for visibility */
  .Box, .btn, .form-control { border-width: 2px; }
}
```

### 6. Scroll Edge Effects
Instead of hard 1px borders under floating chrome, use gradient fades:

```css
.scroll-edge-bottom::after {
  content: '';
  position: absolute;
  bottom: -8px;
  left: 0;
  right: 0;
  height: 8px;
  background: linear-gradient(to bottom, var(--color-header-bg), transparent);
  pointer-events: none;
}
```

## Animations

All animations use Framer Motion with Apple's spring defaults:

```tsx
// Critically damped — no overshoot (default for UI transitions)
<motion.div
  initial={{ opacity: 0, y: 8 }}
  animate={{ opacity: 1, y: 0 }}
  transition={{ type: 'spring', bounce: 0, duration: 0.4 }}
>
  Content
</motion.div>

// Momentum-driven — slight bounce (for gesture-driven interactions)
<motion.div
  animate={{ x: target }}
  transition={{ type: 'spring', bounce: 0.15, duration: 0.4 }}
/>
```

### Spring Parameter Reference

| Interaction | bounce | duration | Rationale |
|-------------|--------|----------|-----------|
| Page entrance | 0 | 0.5-0.6 | Clean, no overshoot |
| Tab switch | 0 | 0.3 | Snappy, no overshoot |
| XP bar fill | 0 | 0.8 | Slow, satisfying fill |
| Toast notification | 0.15 | 0.4 | Slight bounce for delight |
| List item stagger | 0 | 0.3 | Clean, no overshoot |

## Accessibility

- All interactive elements have visible focus states
- Color contrast meets WCAG 2.1 AA (4.5:1 for text)
- Keyboard navigation for all components
- Screen reader labels for icons
- `prefers-reduced-motion: reduce` — replaces springs with instant transitions
- `prefers-reduced-transparency: reduce` — makes materials opaque
- `prefers-contrast: more` — thicker borders on interactive elements
- `scroll-padding-top: 50px` accounts for sticky toolbar
